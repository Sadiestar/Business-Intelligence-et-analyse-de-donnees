# Projet 3 — Requêter une base de données avec SQL

> Produire des résultats fiables à partir d’une base de données relationnelle.

## Contexte

Des informations réparties dans plusieurs tables doivent être interrogées et rapprochées pour répondre à des questions métier.

## Besoin métier

Obtenir des résultats précis, reproductibles et compréhensibles, tout en garantissant la traçabilité des requêtes.

## Démarche

- analyse de la structure de la base ;
- identification des clés et des relations ;
- rédaction de requêtes SQL ;
- contrôle de la cohérence des résultats ;
- documentation de la méthode employée.

## Résultats

La démarche fournit un ensemble de requêtes contrôlées et une documentation technique permettant de comprendre et de reproduire les traitements.

## Impact / recommandations

La documentation sécurise la réutilisation des analyses. La mise en place de contrôles systématiques sur les jointures, les doublons et les valeurs manquantes est recommandée.
