# Projet 2 — Visualiser des données avec Excel

> Transformer des données brutes en analyses lisibles et directement exploitables.

## Contexte

Une équipe de basket-ball désire mieux saisir ses performances au moyen d’un outil d’analyse simple d’accès pour l’entraîneur.

## Besoin métier

Structurer les données, faire ressortir les indicateurs utiles et restituer les principaux enseignements sous une forme claire.

## Démarche

- contrôle et préparation des données dans Excel ;
- construction de tableaux d’analyse ;
- création de visualisations adaptées ;
- synthèse des constats dans une présentation.

## Résultats

Un rapport Excel permet d’explorer les données et une présentation facilite la lecture des résultats par les décideurs.

## Impact / recommandations

La solution améliore l’accès à l’information et fournit une base simple pour suivre les indicateurs dans le temps. Une actualisation régulière et l’automatisation des contrôles sont recommandées.
