Explication pour un data analyst débutant

Un DataFrame Pandas ne se copie pas automatiquement.

Quand on écrit :

df_b = df_a

les deux variables pointent vers le même objet.

Si ensuite on ajoute une colonne :

df_b["nouvelle_colonne"] = ...

la colonne apparaît aussi dans df_a.

Pour créer une vraie copie indépendante, il faut écrire :

df_b = df_a.copy()

C'est une bonne pratique essentielle dans les notebooks d'analyse, car elle évite les effets de bord difficiles à détecter.
