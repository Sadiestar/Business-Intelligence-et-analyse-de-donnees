# Projet 11 — Augmenter un projet data avec l’IA

> Utiliser l’intelligence artificielle de manière critique, documentée et contrôlée.

## Contexte

Un notebook d’analyse existant doit être amélioré avec l’aide de solutions d’intelligence artificielle, sans compromettre la fiabilité ni la traçabilité du travail.

## Besoin métier

Évaluer les apports réels de l’IA pour la revue de code, la qualité des données, la documentation et la restitution, tout en maîtrisant ses limites.

## Démarche

- analyse critique du notebook de référence ;
- définition et test de prompts ;
- comparaison des propositions produites ;
- vérification humaine des corrections ;
- documentation des choix, limites et usages de l’IA.

## Résultats

Le dossier retrace les expérimentations et les arbitrages. La soutenance synthétise les gains observés, les points de vigilance et les conditions d’un usage responsable.

## Impact / recommandations

L’IA accélère certaines tâches de revue et de documentation lorsqu’elle reste encadrée par des contrôles explicites. La conservation des prompts, des versions et des validations humaines est recommandée.
